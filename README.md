# Fischer Chess Coach

Локальный веб-тренажёр шахмат с интерактивным тренером «Бобби Фишер» на русском языке.
Работает полностью на вашем компьютере: без подписок и без обращения к внешним сервисам.

## Что умеет

| Режим | Что делает |
|---|---|
| **Калибровка** | 3 вопроса → 10 адаптивных задач (верно +100, ошибка −75) → мини-партия на 15 ходов (по желанию) → стартовый рейтинг и индивидуальный план |
| **Игра с тренером** | Партия с ботом 400–2400. Тренер реагирует на каждый ход, показывает угрозу при потере больше пешки, даёт трёхступенчатую подсказку (словами → фигура → стрелка) |
| **Тактика** | Задачи Lichess, сложность подстраивается под рейтинг; фильтр по темам |
| **Дебюты Фишера** | 20 линий репертуара (Созин, испанская, французская, Найдорф, староиндийская, Грюнфельд). Режимы «Учить» и «Проверка», реальный процент побед Фишера в каждой позиции |
| **Угадай ход Фишера** | 50 партий (первая — «Партия века»). Ход Фишера +10, первая линия движка +7 |
| **Анализ** | Разбор своей партии или любого PGN: шкала и график оценки, классификация ходов (блестящий … зевок), точность, вердикт тренера с рекомендацией |

Тренер — анимированный SVG-аватар с состояниями `idle`, `talking`, `pleased`, `skeptical`, `thinking`,
облачком диалога и озвучкой через Web Speech API (нужен русский голос в системе).

## Быстрый запуск

### Вариант 1 — Docker

```bash
docker compose up --build
```

Откройте http://localhost:8000. Профиль и история хранятся в томе `coach-data`.

### Вариант 2 — без Docker

Нужны Python 3.10+ и Node.js 20+.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

```bash
cd frontend
npm install
npm run build
```

```bash
cd backend
uvicorn app.main:app --port 8000
```

Откройте http://localhost:8000. При первом старте сервер сам проиндексирует партии Фишера (несколько секунд).

### Режим разработки

Бэкенд: `uvicorn app.main:app --reload --port 8000` в `backend/`.
Фронтенд: `npm run dev` в `frontend/` → http://localhost:5173 (запросы `/api` проксируются на порт 8000).

Тесты API: `pip install -r requirements-dev.txt && pytest` в `backend/`.

## Zero-Hallucination: откуда тренер берёт факты

Тренер **не придумывает партии**. Эндпоинт `POST /api/position-check` получает FEN и:

1. нормализует его (`фигуры + очередь хода + рокировки + взятие на проходе`, без счётчиков);
2. ищет точное совпадение в таблице `fischer_positions` (68 тыс. позиций из 825 партий);
3. если его нет — ищет ту же пешечную структуру (`pawn_hash`);
4. если нет и её — возвращает `match: none`, и тренер молчит.

Соперник, год, турнир, сыгранный ход и результат подставляются в шаблон только из строк базы
(`backend/app/insights.py`). Проценты побед в дебютах тоже считаются из базы.

Что **не** из базы, и это честно разделено в коде:

- реплики тренера (`frontend/src/lib/coachLines.js`) — стилизация под манеру Фишера, не цитаты;
- комментарии к дебютным линиям и типовые планы — учебный материал, написанный вручную;
- подлинные цитаты — короткий список в `QUOTES` с указанием источника. Покомментарных
  аннотаций из книги «Мои 60 памятных партий» в проекте нет: книга защищена авторским правом,
  поэтому поле `annotation` в базе пустое.

## Архитектура

```
frontend/  React + Vite + Tailwind, cm-chessboard, chess.js, Stockfish 19 (WASM, в Web Worker)
  src/lib/engine.js        UCI-обёртка над Stockfish, бот заданного рейтинга
  src/lib/chessUtil.js     классификация ходов, точность, подсказки
  src/lib/useBotGame.js    партия с ботом + оценка каждого хода
  src/components/          доска, аватар, облачко тренера, шкала оценки, нотация
  src/modes/               по файлу на режим
backend/   FastAPI + python-chess + SQLite
  app/insights.py          поиск позиции в партиях Фишера
  app/repertoire.py        линии репертуара + статистика из базы
  app/guess.py             подборка партий для «Угадай ход»
  app/rating.py            Elo, калибровка, план тренировок
  scripts/build_fischer_db.py   индексация PGN → SQLite
  data/                    fischer.pgn, puzzles.csv, openings.tsv
```

Схема базы — в `backend/app/db.py` (таблицы из ТЗ плюс несколько служебных полей и таблиц).

### Пересборка базы партий

```bash
cd backend
python scripts/build_fischer_db.py                  # из встроенного data/fischer.pgn
python scripts/build_fischer_db.py --pgn my.pgn     # из своего архива
python scripts/build_fischer_db.py --download URL   # PGN или ZIP по ссылке
```

Профиль и история при этом сохраняются.

## Данные и ограничения

- **Партии Фишера** — 827 партий из сборника PGN Mentor (в индекс попало 825; в ТЗ названо ~970 —
  более полный архив можно подключить ключом `--pgn`).
- **Задачи** — 2072 задачи из открытой базы Lichess (CC0), рейтинги 400–2900.
- **Названия дебютов** — справочник lichess-org/chess-openings (CC0).
- **Сила бота** приблизительна: от 1320 используется штатное ограничение Stockfish (`UCI_Elo`),
  ниже — минимальный уровень с долей случайных ходов.
- **Рейтинг** считается по формуле Эло (не Glicko-2).
- Аватар — условный рисованный персонаж в костюме, а не портретное сходство.
